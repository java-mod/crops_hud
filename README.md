# Crop Harvest Session HUD

> Minecraft 1.21.4 ~ 1.21.5, 1.21.7 ~ 1.21.8 / Fabric  
> 클라이언트 전용 모드

작물 수확 중인 세션 정보를 HUD로 표시하는 Fabric 클라이언트 모드입니다.  
현재 작물, 수확량, 특수 드랍, 활성 시간, 예상 수익을 실시간으로 보여주며, HUD 위치 편집과 작물 가격 설정을 지원합니다.

## 주요 기능

- **실시간 수확 HUD 표시**
  - 현재 작물
  - 수확량
  - 특수 드랍 횟수
  - 활성 시간
  - 예상 수익
- **상태 배지 표시**
  - `수확 중`
  - `일시정지`
- **HUD 위치 변경 지원**
  - 프리셋 앵커 위치
  - 드래그 편집 화면
- **HUD 배경 표시/숨김 설정**
- **자동 일시정지 대기시간 설정**
- **작물 고정 기능**
- **작물별 가격 설정 및 조회**
- **서버 접속 시 업데이트 확인 알림**
  - 자동 업데이트 없음
  - 새 버전이 있으면 수동 업데이트 안내 메시지만 표시

## 지원 버전

이 프로젝트는 **하나의 코드베이스**를 유지하면서, 지원하는 Minecraft 버전별로 **개별 JAR**을 생성하는 방식으로 배포합니다.

- `1.21.4`
- `1.21.5`
- `1.21.7`
- `1.21.8`

배포 파일 예시:

- `crophud-1.0.4+mc1.21.4.jar`
- `crophud-1.0.4+mc1.21.8.jar`

각 게임 버전에 맞는 JAR만 선택해서 사용하면 됩니다.

## HUD 표시 항목

| 항목 | 설명 |
|------|------|
| 작물 | 현재 추적 중인 작물 이름. 감지 전에는 `감지 대기 중` 표시 |
| 수확량 | 현재 세션에서 수확한 작물 개수 |
| 특수 | 특수 드랍 감지 횟수 |
| 활성 시간 | 실제 수확 중이었던 시간 |
| 예상 수익 | 설정된 작물 가격 기준 누적 예상 수익 |

> 현재 HUD에는 **시간당 수익은 표시되지 않습니다.**

## 세션 동작 방식

### 자동 시작
작물을 수확하면 세션이 자동으로 시작됩니다.

### 자동 일시정지
마지막 수확 이후 일정 시간 동안 추가 수확이 없으면 자동으로 일시정지됩니다.  
기본값은 **5초**이며, `/허드 대기시간` 또는 `/hud pause`로 변경할 수 있습니다.

### 자동 재개
일시정지 상태에서 다시 수확하면 세션이 자동으로 재개됩니다.

### 자동 초기화
작물 고정이 꺼진 상태에서 다른 종류의 작물을 수확하면 기존 세션이 초기화되고 새 작물 기준으로 다시 추적됩니다.

### 연결 종료 시 초기화
서버 연결이 끊기면 현재 수확 세션은 초기화됩니다.

## 특수 드랍 감지

특수 드랍은 수확 세션 HUD의 `특수` 항목에 반영됩니다.  
문서 기준으로 지원되는 특수 드랍 예시는 아래와 같습니다.

| 수확 작물 | 특수 드랍 아이템 |
|-----------|------------------|
| 밀 | 빵 |
| 당근 | 커스텀 이름 당근 |
| 감자 | 구운 감자 |
| 비트루트 | 커스텀 이름 비트루트 |
| 네더와트 | 말린 다시마 |
| 코코아콩 | 쿠키 |
| 수박 | 수박 조각 |
| 호박 | 호박 파이 |

> 사탕수수와 선인장은 특수 드랍이 없습니다.

## 명령어

이 모드는 한국어/영어 명령을 모두 지원합니다.

### 작물 가격 명령어

#### 가격 설정
```bash
/작물가격 설정 <작물> <가격>
/작물가격 설정 <작물> <가격> <행운레벨>
/cropprice set <crop> <price>
```

예시:
```bash
/작물가격 설정 밀 12.5
/작물가격 설정 감자 15 3
/cropprice set wheat 12.5
```

#### 가격 조회
```bash
/작물가격 조회 <작물>
/cropprice get <crop>
```

#### 전체 목록 확인
```bash
/작물가격 목록
/cropprice list
```

### HUD 명령어

#### 세션 초기화
```bash
/허드 초기화
/hud reset
```

#### HUD 위치 변경
```bash
/허드 위치 <앵커>
/hud position <anchor>
```

사용 가능한 위치:

| 한국어 | 영어 |
|--------|------|
| 좌상단 | top_left |
| 우상단 | top_right |
| 중앙상단 | center_top |
| 중앙 | center |
| 좌하단 | bottom_left |
| 우하단 | bottom_right |
| 중앙하단 | center_bottom |

기본 위치는 **우상단**입니다.

#### HUD 편집 화면 열기
```bash
/허드 편집
/hud edit
```

편집 화면에서는 HUD를 직접 드래그해서 이동할 수 있습니다.  
`ESC`를 누르면 저장됩니다.

#### HUD 배경 표시 설정
```bash
/허드 배경
/허드 배경 켜기
/허드 배경 끄기
/hud background
/hud background on
/hud background off
```

#### 자동 일시정지 대기시간 설정
```bash
/허드 대기시간
/허드 대기시간 <초>
/hud pause
/hud pause <seconds>
```

- 설정 범위: **1 ~ 300초**
- 기본값: **5초**

#### 작물 고정
```bash
/허드 작물고정
/허드 작물고정 <작물>
/허드 작물고정 해제
/hud lockcrop <crop>
/hud lockcrop off
```

작물 고정을 켜면 해당 작물만 계속 추적하고, 다른 작물을 수확해도 세션이 바뀌지 않습니다.

## 단축키

기본적으로 HUD 편집 단축키는 지정되어 있지 않습니다.  
게임 내에서 아래 경로로 직접 지정할 수 있습니다.

- `설정 → 조작 → 작물 수확 HUD`

단축키를 지정하면 명령어 없이 바로 HUD 편집 화면을 열 수 있습니다.

## 설정 파일

이 모드는 설정을 자동으로 저장합니다.

- `config/crophud/crophud_hud.json`
  - HUD 위치
  - 커스텀 좌표
  - 배경 표시 여부
  - 자동 일시정지 대기시간
- `config/crophud/crophud_prices.json`
  - 작물별 가격
  - 행운 레벨 정보

## 개발 및 빌드

### 로컬 기본 빌드

기본값은 `gradle.properties`에 정의된 Minecraft 버전을 사용합니다.

```bash
./gradlew clean verifyBuildOutputs -Pskip_build_counter=true
```

`-Pskip_build_counter=true`를 주면 **로컬 테스트 환경에서 build_counter.txt가 증가하지 않습니다.**

### 특정 Minecraft 버전으로 빌드

버전별 빌드는 Gradle 프로퍼티를 주입해서 수행합니다.

```bash
./gradlew clean verifyBuildOutputs \
  -Pskip_build_counter=true \
  -Pminecraft_version=1.21.8 \
  -Pyarn_mappings=1.21.8+build.1 \
  -Ploader_version=0.16.14 \
  -Pfabric_api_version=0.128.0+1.21.7 \
  -Pminecraft_dependency="~1.21.8"
```

### 모든 지원 버전을 한 번에 빌드

```bash
./gradlew buildAllSupportedMcVersions
```

로컬 전체 빌드는 **순차적으로** 실행되며, 생성된 JAR는 아래 경로에 모입니다.

- `dist/mc/1.21.4/`
- `dist/mc/1.21.5/`
- `dist/mc/1.21.7/`
- `dist/mc/1.21.8/`

빌드 후 산출물 확인만 따로 하고 싶다면 아래 명령을 사용할 수 있습니다.

```bash
./gradlew verifyAllSupportedArtifacts
```

### CI 릴리즈 방식

- PR / 일반 검증: 지원 버전 matrix 기준으로 버전별 빌드만 수행
- `main` 브랜치 반영 시: 버전별 JAR를 모두 생성하고 하나의 릴리즈에 함께 업로드
- 릴리즈 버전은 동일하지만, 산출물은 Minecraft 버전별로 분리됩니다

## 업데이트 정책

- 서버/월드 접속 시 최신 버전을 확인합니다.
- 새 버전이 있으면 채팅으로 알림을 표시합니다.
- **자동 다운로드 및 자동 업데이트는 지원하지 않습니다.**
- 업데이트는 사용자가 직접 릴리즈 페이지에서 받아서 교체해야 합니다.
